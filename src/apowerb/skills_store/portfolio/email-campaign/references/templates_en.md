# Email Templates — English

Reference templates. Always adapt tone, length and CTA to the real context. Never paste a template as-is without personalization.

## 1. Cold outreach

**Subject**: A quick idea for {{company}}

```
Hi {{firstname}},

Noticed {{company}} is working on [industry / recent signal]. At [our company] we help similar teams [concrete outcome in one line].

Worth a 15-min chat this week to see if it's relevant on your side?

Best,
[Name]

---
Not interested? Just reply "stop" and I won't reach out again.
```

## 2. Follow-up (no reply to first message)

**Subject**: Re: my last note

```
Hi {{firstname}},

Circling back in case my previous message got buried.

The key question: [restate the value in one sentence].

A slot this week or next?

[Name]
```

## 3. Newsletter (opt-in audience)

**Subject**: [Clear topic — one concrete benefit]

```
Hi {{firstname}},

This month:
- [Point 1 — one line]
- [Point 2 — one line]
- [Point 3 — one line]

👉 [Main CTA]: [link]

Talk soon,
[Name / team]

---
Unsubscribe: [link]
```

## 4. Announcement / launch

**Subject**: [Product / feature] is live

```
Hi {{firstname}},

We just shipped [name]. In one line: [what it does and who it's for].

In practice, it lets you [benefit 1] and [benefit 2].

[CTA — see the demo / try it]: [link]

[Name]
```

## Quick rules

- Subject < 60 chars, no ALL CAPS, no "!!!".
- Body < 120 words for prospecting/follow-up.
- One CTA per email.
- Identifiable signature (name + company).
- Opt-out footer for any cold outreach.
