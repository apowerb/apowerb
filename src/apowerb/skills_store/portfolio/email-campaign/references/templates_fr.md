# Templates d'emails — Français

Templates de référence. Adapte toujours le ton, la longueur et le CTA au contexte réel du user. Ne colle jamais un template tel quel sans personnalisation.

## 1. Prospection froide (cold outreach)

**Objet** : Une idée pour {{company}}

```
Bonjour {{firstname}},

Je vois que {{company}} évolue dans [secteur / signal récent]. Chez [notre société], on aide des équipes similaires à [résultat concret en 1 phrase].

Est-ce que 15 min cette semaine pour voir si ça a du sens de votre côté ?

Bien cordialement,
[Nom]

---
Si ce message ne vous intéresse pas, répondez simplement "stop" et je ne vous recontacterai plus.
```

## 2. Follow-up (relance après 1er contact sans réponse)

**Objet** : Re: notre échange

```
Bonjour {{firstname}},

Je reviens vers vous au cas où mon précédent message serait passé inaperçu.

La question clé : [reformuler la valeur en 1 phrase].

Un créneau cette semaine ou la suivante ?

[Nom]
```

## 3. Newsletter (audience opt-in)

**Objet** : [Sujet clair — 1 bénéfice concret]

```
Bonjour {{firstname}},

Ce mois-ci :
- [Point 1 — 1 ligne]
- [Point 2 — 1 ligne]
- [Point 3 — 1 ligne]

👉 [CTA principal] : [lien]

À bientôt,
[Nom / équipe]

---
Se désinscrire : [lien]
```

## 4. Annonce / lancement

**Objet** : [Produit / feature] est disponible

```
Bonjour {{firstname}},

On vient de sortir [nom]. En une phrase : [ce que ça fait et pour qui].

Concrètement, ça vous permet de [bénéfice 1] et [bénéfice 2].

[CTA — voir la démo / tester] : [lien]

[Nom]
```

## Règles rapides

- Objet < 60 caractères, pas de MAJUSCULES, pas de "!!!".
- Corps < 120 mots pour prospection/follow-up.
- Un seul CTA par email.
- Signature identifiable (nom + société).
- Pied de page opt-out pour toute cold outreach.
