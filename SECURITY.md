# Security Policy

## Supported Versions

We release security patches for the versions listed in the table below.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `apowerb` seriously. If you believe you have found a security vulnerability, please do **NOT** open a public issue or pull request on GitHub.

### How to Report

Please report security issues through one of the following methods:

1. **GitHub Security Advisory (Preferred):**
   Submit a private report via [GitHub Security Advisories](https://github.com/apowerb/apowerb/security/advisories/new).

2. **Email:**
   If you prefer email, send details to **[YOUR-EMAIL@DOMAIN.COM]**.

### What to Include in Your Report

To help us assess and resolve the issue quickly, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal reproducible example (Proof of Concept).
- Your Python environment details (Python version, OS, `apowerb` package version).

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Assessment:** We will evaluate the report and confirm the vulnerability or request more information.
- **Fix & Advisory:** Once confirmed, we will work on a fix, issue a patched version, and publish a Security Advisory with credit to you (unless you prefer to remain anonymous).

Thank you for helping keep `apowerb` safe for everyone!
